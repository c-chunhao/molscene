# MolScene v0.6 biological assemblies and trajectory analysis

Date: 2026-10-17 (Asia/Shanghai). User authorizes implementation, testing, GitHub publication and F-drive local upgrade without per-step approval. All choices below are implementation decisions.

## Intent and scope

Add common biological assembly and coordinate-trajectory workflows to the existing original PyMOL/Qt workbench. Keep the five pages and use independent workers, frozen local inputs, closed artifact bundles, explicit loading of derived copies and real native acceptance.

## Constraints

- All new files, worktrees, environments, caches, examples and evidence stay on F: under the existing MolScene project directory. Existing tools on other drives may be read/run. No global configuration changes.
- Python >=3.10, lazy PyMOL/Qt/NumPy imports; backend-free CLI help and request validation remain usable. NumPy is supplied by the compatible PyMOL scientific runtime; no new mandatory package.
- Preserve existing rendering, timelines, density, electrostatics, labels, persistence and public examples. Do not redistribute proprietary software or make commercial parity claims.
- New bundles use Bundle(new_directory_only=True), checked_path, complete manifests and artifact hashes; cancellation publishes no successful partial bundle. Protect original inputs, private copies, job and envelope on validation/error paths.

## Biological assembly

Read deposited PDB REMARK 350 BIOMT definitions and PDBx/mmCIF assembly, assembly_gen and oper_list tables. List assembly IDs and available chain/operator counts before building. Accept explicit local source_path, assembly_id (default '1') and coordinate state (default 1). Never infer an assembly from contacts or generic lattice neighbors; deposited operators are retained regardless of operator type.

Use a bounded, Qt/backend-free CIF1 tokenizer/table reader (quotes, semicolon text, comments, scalar and loop values; reject ambiguity/malformed data). Source cap 20 MiB; expanded operator cap 512 and generated atom cap 200000. Handle comma lists, integer ranges and parenthesized Cartesian products with right-to-left affine composition, never eval. Reject missing/duplicate IDs, absent chains, incomplete/nonfinite/nonrigid transforms, invalid state or empty output before publication.

In mmCIF generation asym_id_list is label_asym_id, represented by PyMOL segi; author chain remains intact. PDB blank-chain NULL maps to the empty chain. Scope native reader settings and verify source membership. One output molecular object per generation/operator copy retains original chain/residue/atom identity. Use exact native indices rather than unsafe interpolated selections.

Keep source bytes and ASU immutable. Write source input, per-copy CIF files, assembly.pse, copies.csv, report.json, manifest.json and relative standalone replay.pml. Report operation='assembly', source hash, chosen state/assembly, original asym/author-chain membership, operator sequence, matrix and atom count per copy, complete counts and limitations. Independently reload coordinates and compare core identity/world geometry <=0.001 angstrom. Real deposited nonidentity fixture 3C70.cif plus original tiny PDB/CIF fixtures prove expansion and label/auth distinction.

Public interfaces: assembly.assembly_catalog(path)->dict; assembly.validate_assembly_request(request)->dict; assembly.build_assembly(cmd,source_path,*,assembly_id='1',state=1,cancelled=None,progress=None)->dict; assembly_export.export_assembly(input_session,output_dir,request,*,cancelled=None,progress=None,protected=())->dict. input_session must be None for deposited-source builds. Exact returned build/report row keys are documented by Task 1 for integration.

## Trajectory analysis

Analyze one explicit fixed-topology molecular object in an existing PSE or multi-model coordinate input. Defaults: object required in GUI, selection='name CA', fit_selection='name CA', reference_state=1, start=1, stop=None, stride=1, align=True, time_step_ps=None, time_start_ps=0.0. At least two sampled coordinate states; reference may be outside the sampled range. Freeze reference membership and reject changed atom identity, missing coordinates, nonfinite values, discrete/ambiguous topology and out-of-range states. MAX_FRAMES=2000, MAX_ATOMS=100000, sampled frame*atom count <=2000000. Spatial/state-dependent expressions resolve once at reference; then exact members are used.

Use uniform-weight proper Kabsch fitting on at least three noncollinear fit atoms. Apply that transform only to copied arrays, never the live or snapshot source. RMSD is against the reference measurement coordinates after the chosen fit; RMSF is per-atom population fluctuation about the sampled mean after the same fit; per-residue RMSF is explicitly sqrt(mean(atom RMSF squared)). Rg is equal-weight sqrt(mean squared distance from each frame's measurement centroid), not mass-weighted. Report raw and fitted RMSD, Rg in angstrom and per-atom/per-residue RMSF, selected identities, frame mapping and fitting parameters. Use numerically stable accumulation and finite checks. Reject degenerate fit geometry. Require determinant +1 rather than permitting a reflection transform; reflected input configurations remain valid and retain their nonzero proper-fit residual.

Provide optional local DCD import using the explicit object's existing single-state topology, native public load_traj and a bounded validated DCD header; cap file size 256 MiB and frame/atom product before load. Support only 32-bit little-endian CHARMM DCD with positive declared frame count, full atoms, 3D float32 coordinates and no fixed atoms, extra/unit-cell blocks or fourth dimension. Strictly scan every Fortran record length/trailer and all finite coordinates before native loading; declared counts alone are insufficient. Enforce native loaded frame count, exact full topology and independently decoded coordinate ordering. No topology-only dummy frame, append, native interval decimation or implicit fit. Reject other variants clearly. Multi-state coordinate/PSE analysis remains fully available independent of DCD support. Require pre-imaged/unwrapped molecules and document no PBC correction even for cell-less files. Time is coordinate-state index unless the user supplies positive finite time_step_ps; time(state)=time_start_ps+(state-1)*time_step_ps.

Write source.pse, optional inputs/trajectory.dcd, frames.csv, atoms.csv, residues.csv, rmsd.svg, rmsf.svg, rg.svg, report.json, manifest.json and standalone relative replay.pml. Plot SVG is self-contained escaped UTF-8 with bounded data and explicit axes/units; no external scripts, URLs or plotting dependency. No inferred physical time. Export analysis artifacts only; do not replace source coordinates with fitted states or alter B factors.

Public interfaces: trajectory.validate_trajectory_request(request)->dict; trajectory.trajectory_analysis(cmd,request,*,cancelled=None,progress=None)->dict; trajectory_export.export_trajectory(input_session,output_dir,request,*,cancelled=None,progress=None,protected=(),source_input=None)->dict. Optional source_input={'path':absolute_path,'sha256':captured_digest} archives and hash-binds an original CLI coordinate source, separately from the captured session. Request canonical object key is 'object_name', optional external key 'trajectory_path' defaults to None. Report operation='trajectory'; top-level frames/atoms/residues list[dict] supports Results tables.

Builder decisions: one original object must have <=100000 full-topology atoms. For normal loaded-state analysis, the <=2000000 budget is union(fit,measurement) atom count times unique(sampled states plus reference) count, before coordinate iteration; align=False excludes fit members and ignores fit-selection emptiness/rank, fitted_rmsd_angstrom is null, reported rmsd uses raw coordinates. DCD additionally requires full declared frame count <=2000 and full-topology atoms times every decoded frame <=2000000 before native loading, independent of requested stride. Load all source frames starting at state 1 and sample only afterward, so source DCD frame equals loaded state. Count/decoder checks cannot prove chemical atom correspondence: DCD contains no atom names and caller must provide topology in its original atom order; report this explicit provenance requirement. Original fixtures independently test decoding/order and native convention, without generalizing that into proof for arbitrary user DCD.

## Worker, CLI and GUI integration

Extend advanced.EXPORTS/PARAMETERS validation and dispatch, guarded source_paths and worker raw protection/role validation for source_path and trajectory_path. Assembly uses no live PSE; trajectory freezes a PSE. Private original-file copies retain the same SHA and cannot be overwritten through output/envelope errors. Bind operation/request and original role/hash to prepared context.

CLI: assemblies INPUT prints catalog JSON; assembly INPUT --assembly-id 1 --state 1 --output NEWDIR; trajectory INPUT --object NAME --selection ... --fit-selection ... --reference-state 1 --start 1 --stop N --stride 1 --no-align --time-step-ps DT --time-start-ps T --trajectory FILE.dcd --output NEWDIR. INPUT trajectory is PSE/PDB/mmCIF; default object name when loading coordinate input is 'trajectory_source' (CLI --object defaults to it; PSE requires its actual name). Help works with no backend.

GUI Structure contains a collapsible Biological assembly section with source browser, assembly catalog/ID, state, new output directory, Build and explicit Load copies. Analysis contains collapsible Trajectory with object selector, independent fit/measurement selections, reference/start/stop/stride, fit toggle, optional DCD browse, optional time spacing and new output directory, Analyze. Keep Results and Cancel accessible during worker execution. Show counts, units, complete frames/atoms/residues/copy tables and paths to plots/replay. No webview or new top-level tab. Narrow widths 360/420/540/800 remain usable.

Freeze trajectory identity across sampled and reference states on the original object; derived copies should not stale it. For optional DCD the original object has one topology state: capture all original topology members at state 1 plus request and DCD file hash; resolve analysis membership at its requested reference after private import in the worker. Assembly currentness binds original source file/hash and epoch. Context-bound completion must acquire its report path before record_result so successful new results are not shown unverified. Validate closed bundle before explicit copy loading; preserve camera and session_file, allocate collision-free names, rollback only owned objects on load failure. Never auto-open external SVG/browser/third-party input code. Plot paths are shown as local artifacts.
