# MolScene v0.5 daily workflows implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add typed polar-contact candidates, guided labels, coordinate/session
persistence and compact desktop controls, then verify and publish 0.5.0.

**Architecture:** Keep instance-bound public PyMOL operations in Qt-free modules.
Use existing legacy analysis snapshots for polar calculations and guarded
cooperative advanced bundles for persistence. The controller connects these
services to the five retained pages; UI-only helpers own navigation and dialogs.

**Tech Stack:** Python, unittest, public PyMOL API, existing Qt5/Qt6 bindings,
standard-library persistence, existing Bundle and worker protocols.

**Spec:** `docs/superpowers/specs/2026-10-16-daily-v05-design.md`

## Global Constraints

- Keep Python >=3.10, Qt5/Qt6 compatibility, lazy backend imports and no new runtime dependencies.
- New local source, dependencies, temporary files, caches, examples and evidence stay on F:.
- Preserve the five existing pages and indices: Structure, Figure, Analysis, Results, Advanced.
- Preserve v0.2/v0.3/v0.4 workflows and examples; no commercial binary/license copying or parity claims.
- Polar defaults: state 1, cutoff 3.5 Å (strict native `<`), angle 45 degrees, primary blank+A altloc, maximum 100,000 pairs. Cutoff 0.1..10; angle 0..90; finite values only.
- Polar preflight cap: unique undirected typed heavy A/B non-self pairs at distance <= cutoff, before angle/direct-bond exclusions. The same declared cap separately limits final unique directed output.
- Polar annotation shows at most 200 pairs; complete JSON/CSV is never truncated.
- Guided labels: atom/residue/chain_residue/custom; apply at most 500 labels, native positive size 8..48 scoped to target objects at the requested state (shared by labels there), resolved target-only color. Report size_scope/size_objects; preserve other objects/states settings. Exact recipe text and anchor order are defined in the spec.
- Coordinates: one numbered file per source object, one explicit positive state, cif default or pdb, at most 200,000 atoms and 1,000 objects. Reload core identity includes element/name/resn/full resi/chain/segi/alt; Euclidean error <=0.001 Å.
- Persistence uses new-directory-only closed Bundle publication, cooperative cancellation and protected inputs. No PNG/ray/OpenGL required. Do not weaken any existing guard.
- Existing 12 native/science/replay/encoder and 8 Linux protection identities remain required. Add `test_daily_gui.NativeDailyTests.test_native_daily_polar_labels_exports_and_narrow_navigation`; all 21 actually execute successfully before release.
- Root owns native focus, full release gates and GitHub publication. Workers must not spawn subagents or independently run full native/solver/release jobs.

## Review Focus

1. Same-coordinate bond/charge/native-role changes invalidate polar freshness (Task 1).
2. Literal unusual residue text and partial selections do not evaluate text or expand anchors (Task 2).
3. Transformed objects with overlapping residue IDs export separately with actual requested-state/world geometry (Task 3).
4. Existing destinations, linked ancestors and cancellation cannot replace source/old results or publish a partial bundle (Task 3).
5. Narrow page selectors and dialog modes cannot bypass mutation locks or fresh-output rules (Task 4).

### Task 3: Guarded coordinate and session snapshot bundles

**Files:** Create `molscene/persistence.py`, `tests/test_persistence.py`,
`tests/test_persistence_worker.py`; modify `advanced.py`, `cli.py`,
`desktop/controller.py`, `desktop/jobs.py` and worker dispatch as needed.

**Interfaces:**
- Produce `persistence.validate_persistence_request(operation, request) -> dict`, for `coordinates` or `session_save`.
- Produce `persistence.export_persistence(input_session, output_dir, operation, request, *, cancelled=None, progress=None, protected=()) -> dict`.
- Register cooperative advanced operations `coordinates` and `session_save`, both using `{'request': ...}` and private cancel marker. The input is a protected frozen PSE snapshot. Reuse advanced envelope/source binding and Bundle rather than inventing a second file transaction protocol.
- Coordinates request contains selection/state/format; session_save request is empty. CLI `coordinates INPUT ...` loads an explicit local coordinate/PSE input and makes its private snapshot before service dispatch; `session-save SESSION.pse --output ...` uses a validated PSE. Temporary files use the configured task drive.
- Controller preparation freezes coordinate selection members/state and snapshot provenance; full session saves have explicit captured-snapshot semantics. Result metadata `result_kind='saved_snapshot'` and `snapshot_status='saved'` never masquerade as live scientific current/stale verification. No automatic load or annotation.
- Return schema-2 successful report with output path, inputs/snapshot hash, numbered object-file mapping, complete membership CSV, reload diagnostics, explicit format limitations, replay and closed hashes. Session bundle uses byte-preserved `session.pse`.

- [ ] Write failing tests for transformed state-2 atoms, two source objects with identical identifiers, unusual/insertion/alt/segment IDs, native PDB width rejection, precision and independent reload. Assert all core identity fields and original source object/index mappings separately.
- [ ] Observe RED. Implement cif/pdb validation, numbered per-object files and fresh-backend reload verification. PDB truncation fails before publication; arbitrary object names never become output paths. Preserve source view, current state, atoms/bonds/settings and inputs.
- [ ] Add complete PSE save/reopen tests including multiple states, labels, scenes and a valid map; do not trigger a renderer. Coordinate replay loads files; session replay loads the saved PSE through public calls without MolScene.
- [ ] Add protected-input/output collision, linked ancestor/alias, pre-cancel and cancellation-between-files cases; no truncated successful report, no changed old result. Actual supported link tests run; unsupported filesystem cases retain explicit skip reasons.
- [ ] Integrate advanced validation/service/worker/cooperative cancellation/controller APIs and CLI. Persist failure envelopes under existing safe protocols. Check source snapshot hash and operation/request binding. Verify lazy parse/help without backend.
- [ ] Run focused persistence, real worker, advanced-controller/worker and CLI regressions; retain RED/GREEN, self-review and commit. GUI and native lifecycle belong to Task 4/root.
