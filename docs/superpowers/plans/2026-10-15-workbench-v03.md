# MolScene v0.3 daily workflow implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close common workflow gaps with exact residue navigation, live presets,
clean copies, scene editing and reproducible interface-area analysis, then
publish a tested v0.3.0.

**Architecture:** Retain native upstream rendering and the original four-tab
MolScene dock. Scientific functions stay Qt-free; heavy GUI analysis runs in
existing PSE snapshot workers. Structure helpers and navigation widgets are
separate focused modules, with controller methods retaining main-thread checks.

**Tech Stack:** Python >=3.10, public PyMOL cmd/pymol2, optional PyQt5 or
PySide6-Essentials 6.8.1, stdlib unittest, Pillow, setuptools/uv, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-15-workbench-v03-design.md`.

## Global Constraints

- Python >=3.10; backend and Qt remain optional and lazily imported.
- Original MIT workflow code only; no proprietary code, binaries, assets or license material.
- Existing v0.1/v0.2 command defaults, report schema_version 2 and replay contracts remain compatible.
- Every scientific selection uses an explicit positive state; absent states fail without singleton fallback.
- All new local files, runtimes, caches, temporary data, worktrees and evidence stay on F:.
- GUI native Qt5/PyQt5 and Qt6/PySide6 remain supported; no native assertion or dependency gate is weakened.
- Original coordinates, atom identities, B-factors and unrelated object styles remain unchanged by navigation, presets and analyses.
- Scientific results retain source fingerprints; stale data cannot silently become current; filtered previews never truncate exported tables.

## Review Focus

1. Blank/multi-character chain, segments, insertion/negative residue IDs and
   duplicate numbering across objects must select exactly the original rows.
2. State 2 spatial membership and absent states must not fall back to displayed
   frame/state 1; stale browser identities must fail before mutation.
3. Presets and clean-copy failures must preserve unrelated object styles and
   all original coordinate states/properties/bonds, with no leaked objects.
4. Interface parties that overlap after filtering must fail; same residue split
   across parties must yield separate A/B rows; no extra context atoms.
5. A filtered/sorted GUI preview and background worker must preserve complete
   result/export data and the native close/cancel lifecycle on Qt5 and Qt6.

## Task 2: Exact live structure workflows

**Files:** Create `molscene/desktop/structure.py`, `tests/test_structure_tools.py`;
modify `molscene/desktop/controller.py`. Do not edit Qt panels in this task.

**Interfaces:** Controller methods consumed by Task 4:

```python
residues(selection='all', *, state=1) -> list[dict]
select_residues(rows, *, state=1) -> dict  # capture schema with 'selection'
selection_summary(selection, *, state=1) -> dict
save_selection(name, selection, *, state=1) -> dict  # same capture schema
delete_selection(name) -> None

hide_context(selection, *, state=1, solvent=True, hydrogens=True) -> dict

             frame=True) -> dict

                  remove_hydrogens=False, altloc='primary') -> dict
update_scene(name) -> None

```

`residues` rows have object,segi,chain,resi,resn,state,atom_count,polymer,
one_letter and `atoms` (full original identity rows, including object/index and
state). Polymer is protein/nucleic/other; one_letter is observed code or empty.

selection,source,state,atoms count,objects,identities. Summary includes
atom_count,residue_count,state,objects. Preparation report includes
object,state=1,source_state,selected_atom_count,retained_atom_count, removed
stage counts, retained `identities`, parameters; preserve alternate labels.
Preset names are exactly overview/surface/pocket. Return explicit selected,
ligand and pocket atom/residue counts where applicable and definition.
